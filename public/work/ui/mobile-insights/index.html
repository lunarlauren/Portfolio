Mobile Insights

A construction dashboard has a lot to say, and a phone has very little room. I helped design Hoylu's shipped Mobile Insights experience around that tension.

Project notes · Visual samples coming soon

About the work

Hoylu Mobile Insights is a shipped product experience. My role was UX/UI design for its mobile insights work, framed around project managers checking construction-project information away from a desktop. A dashboard cannot simply be squeezed onto a phone: status, changes, and supporting context compete for limited space. The challenge was to make short checks useful without stripping away the information needed to understand an insight. This describes the use case, not a research-validated persona.
